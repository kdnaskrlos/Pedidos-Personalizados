# Comic Shop · Pedidos

App de registro de pedidos (Personalizado y Sublimación Completa) para el taller.
GitHub Pages + Firebase (Authentication + Firestore). Usuarios con usuario y PIN creados por el administrador.

- `index.html`: la app completa
- `config.js`: datos del proyecto de Firebase (se edita una vez)
- `firestore.rules`: reglas de seguridad (se pegan en Firebase)
- `manifest.webmanifest`, `sw.js`, `icon-*.png`: para instalarla como app

Instalación paso a paso: **[GUIA.md](GUIA.md)**
